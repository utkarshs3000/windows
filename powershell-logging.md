## [Windows Lab]

## // PowerShell Script Block Logging

## What I practiced

 I enabled PowerShell Script Block Logging, ran a PowerShell command and checked its activity in Event Viewer.

## What I learned

 Event ID 4104 records PowerShell script block activity and can show commands that were executed.

## SOC Relevance

 PowerShell logging helps investigate suspicious commands, scripts and PowerShell-based activity on a Windows system.
