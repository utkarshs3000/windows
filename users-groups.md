## [Windows Lab]

## // User Groups and Privileges

## What I practiced

 I created a local user, checked local users and groups, and added and removed the user from the Administrators group using PowerShell.

## What I learned

 Windows uses local users and groups to control account access and privileges. Administrator group membership gives a user higher system permissions.

## SOC Relevance

 Checking user accounts and group membership can help find unauthorized accounts or unexpected privilege changes during an investigation.
