## // Registry Basics

## What I practiced

 I checked a Windows startup Registry location and created, viewed and removed a test Registry key using PowerShell.

## What I learned

 The Registry stores important Windows settings, and some locations like the `Run` key can control programs that start automatically.

## SOC Relevance

 Checking Registry changes can help find suspicious startup entries, persistence methods or unwanted system changes.
