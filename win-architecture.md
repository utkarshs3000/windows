## [Windows Lab]

## //  System

&emsp;Windows version: 2009  
&emsp;Architecture: 64-bit

## What I practiced

&emsp;I checked the basic Windows system information and explored Task Manager to understand how users, processes and services are represented.

## What I learned

&emsp;Windows runs applications as processes and uses services for background system functions. Users, processes, services, the Registry and event logs are important areas to check during a security investigation.

## SOC Relevance

&emsp;Understanding where Windows stores system and activity information helps me know where to start when investigating an alert.
