## [Windows Lab]

## // Administrator Group Changes

## What I practiced

 I filtered Windows Security logs for Event ID 4732 to check when a user was added to a local security group.

## What I learned

 Event ID 4732 shows when a user is added to a local group. In this case, the `soclab` user was added to the Administrators group by subject `utkarsh`.

## SOC Relevance

 Checking group changes can help spot unexpected privilege changes or unauthorized admin access.
