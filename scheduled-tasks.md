## [Windows Lab]

## // Scheduled Task Monitoring

## What I practiced

 I created a scheduled task to start Notepad and then checked its activity in Task Scheduler and Event Viewer.

## What I learned

 Scheduled tasks can automatically run programs at a set time, and their activity can be reviewed through Task Scheduler logs.

## SOC Relevance

 Checking scheduled tasks and their logs can help find suspicious automation or persistence used to run programs without direct user action.
