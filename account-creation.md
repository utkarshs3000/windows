## [Windows Lab]

## // User Account Creation Logs

## What I practiced

 I filtered Windows Security logs for Event ID 4720 to check when a new user account was created.

## What I learned

 Event ID 4720 records user account creation details, including the account that created it and the new account name.

## SOC Relevance

 Checking account creation events can help spot unexpected or unauthorized user accounts on a Windows system.
