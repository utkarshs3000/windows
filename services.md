## [Windows Lab]

## // Services

## What I practiced

 I checked Windows services using PowerShell and the Services console. I also checked the status of Microsoft Defender and Windows Event Log services.

## What I learned

 Windows services run important background functions and can be checked to see whether they are running or stopped.

## SOC Relevance

 Checking service status can help identify stopped security services, unusual services or changes that may need investigation.
